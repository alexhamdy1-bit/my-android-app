# الشريف اسكوتر — Android

مشروع Android Studio كامل لنسخة أولية أوف لاين.

المميزات:
- واجهة داكنة
- إضافة المنتجات: الاسم، الكمية، سعر شراء القطعة، سعر بيع القطعة
- تسجيل المبيعات وتخفيض المخزون
- مشتريات الشغل
- مصروفات
- سجل العمليات
- زر إنهاء اليوم وملخص اليوم
- تخزين محلي بدون إنترنت

## بناء APK
افتح المجلد في Android Studio، انتظر Gradle Sync، ثم:
Build > Build APK(s)

سيظهر APK التجريبي داخل:
app/build/outputs/apk/debug/app-debug.apk
